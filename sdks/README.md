# Etiquetta SDKs

Server-side and framework-specific SDKs for [Etiquetta](https://etiquetta.com).

| Package | Description |
| ------- | ----------- |
| [`@etiquetta/node`](./node) | Core server-side tracking client for Node, Bun, Deno, and any `fetch`-capable runtime. |
| [`@etiquetta/next`](./next) | Next.js integration: browser script component, server-side tracking, Edge middleware. |

## Building

```bash
cd sdks/node && bun install && bun run build
cd sdks/next && bun install && bun run build
```
